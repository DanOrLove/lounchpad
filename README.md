# Lunchpad

Небольшой нативный лаунчер для macOS на SwiftUI. Он показывает приложения из `/Applications`, умеет искать и запускать их, собирать в папки и менять прозрачность окна.

## Сборка

Требуется macOS 14 или новее и Swift 6. Запустите в терминале из этой папки:

```sh
./build-app.sh
open dist/Lunchpad.app
```

Список приложений можно обновить кнопкой внизу окна или сочетанием `⌘R`. Папки и уровень прозрачности сохраняются в пользовательских настройках.

Двойное нажатие на значок запускает приложение. Для папки перетащите один значок на другой, либо создайте папку кнопкой вверху и перемещайте приложения через контекстное меню.
